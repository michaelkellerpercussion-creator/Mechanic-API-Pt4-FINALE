This is my Backend Module 2 Project: API Development and CI/CD Pipeline.

Here I established my Continuoous Integration and Continuous Deployment Pipeline. Once the code is pushed to GitHub it is tested, if the tests pass the code is then pushed to Render where it undergoes deployment. If everything passes, my code is then deployed to my API where it is thoroughly documented.

I also cleaned up my file organization, reduced code redundancy in my test files, reconfigured the Swagger documentation to include additional error messages and fix bugged pathways.
